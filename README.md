# orwell-ignorance-is-strength-zh
Orwell: Ignorance is Strength 简体中文汉化

《奥威尔：无知即力量》个人简体中文本地化补丁，仅供交流与自用，请勿用于商业用途。

本项目使用 ChatGPT / Codex 辅助翻译与技术实现，最终内容由人工审核校对并完成实机测试。
最新版本请前往 Releases 下载。

## 安装

1. 下载 `Orwell-ZH-1.0.1.zip` ，解压后双击运行 `Orwell-ZH-1.0.1-Delta.exe`
3. 选择 `1 安装汉化`
4. 选择/粘贴游戏目录，即包含 `Ignorance.exe` 的文件夹
（Steam 中右键游戏 → 管理 → 浏览本地文件，即可找到游戏目录。）

安装完成后进入游戏，语言选择 **English** 即可。

## 还原原版

1. 关闭游戏，重新运行补丁器
2. 选择 `2 恢复原版`
3. 选择游戏目录
4. 选择安装汉化时生成的备份目录

备份默认保存在游戏目录旁的：

`Orwell-ZH-Backups`

**请勿在确认不需要还原前删除该文件夹。**
